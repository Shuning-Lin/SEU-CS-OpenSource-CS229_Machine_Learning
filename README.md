# ***SEU-CS-OpenSource***系列之 $\color{red}{机器学习}$
本仓库是面向**机器学习**课程的资料分享，可以看到仓库中有两个文件夹————**Stanford_ML_2025**以及**浙江大学_机器学习_2017**,这两门课程在网上都有录播视频，而本仓库包含两门课(部分)程配套作业（注：更确切地来说，Stanford这份是2025年Summer学期开的课的配套作业）

如果翻看仓库，你会发现浙江大学_机器学习_2017里面仅仅包含两个实验：SVM和MLP实验。这里发布者并没有漏传也不会继续更新，理由是2017年的这门课已经距今非常遥远了，课程体系比较陈旧(比较有意思的是当年Google团队的Transformer架构刚刚问世)，代码采用TensorFlow架构(目前主流框架为Pytorch)，不过出于纪念的原因，这里还是特地留了一个位置给它。

不得不说，Stanford的CS229 Machine Learning是一门承前启后的课程，既有**传统统计机器学习的严谨**又**紧跟现代大语言模型的步伐**，非常值得对人工智能感兴趣的各位去听一听，还有对应的课程学习笔记CS229 Lecture Note，搭配课程视频食用，甚是美味！

虽然该仓库属于 ***SEU-CS-OpenSource***系类，但是实际上和东南大学机器学习课程体系并没有关系，只是本人想要将其归于该系列，没错，仅此而已。

最后，值得一提的是，本人实际上是出于**科研训练**的原因，系统学习了这门课程。无论是否出于功利，毕竟也花了许多精力，所以祝愿自己能够在**科研训练**的过程中有所产出！
